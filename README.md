# Customer Support Bot

**Customer Support Bot** is an AI-powered chatbot designed using [Next.js](https://nextjs.org/) to assist users by answering frequently asked questions and providing support.

## Features

- **AI-Powered Responses**: Utilizes AI to generate accurate and helpful responses to user inquiries.
- **Interactive Chat Interface**: Engaging UI that facilitates smooth user interactions.
- **Responsive Design**: Optimized for various devices, ensuring accessibility on desktops, tablets, and mobile phones.
- **Customizable FAQ**: Easily update and manage the list of frequently asked questions.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: MaterialUI
- **Deployment**: [Vercel](https://vercel.com/)
